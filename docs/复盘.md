### 哪些自己拍板
1. **需求澄清全部手写**：目标、输入输出、清洗规则、统计规则、边界、验收标准，未交给 AI。

4. **测试用例数量**：确认至少 2 个边界用例，实际写了 3 个 + 1 个异常用例。
5. **输出路径**：确认输出到 output/，原始文件 data/ 只读。

### 哪些风险做了人工审查
1. **修改原始数据风险**：审查 AI 代码，确认 clean_sales 和 build_stats 都用了 df.copy()。
2. **异常崩溃风险**：审查 main()，确认文件不存在、读取失败、空文件、缺字段、清洗后无数据都有中文提示。
3. **原始文件被写回风险**：确认读取用 pd.read_excel，输出用 pd.ExcelWriter 写到 output/，未触碰 data/。
4. **编码风险**：首次贴代码时 VS Code 用了 GBK，中文乱码导致 import 失败，改为 UTF-8 后正常。

### 如果重做会改进什么

2. AI 对话记录每轮立刻写，不攒到最后。
3. 测试用例可以再加一个"单价为字符串"的边界。

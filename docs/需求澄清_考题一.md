# 考题一 需求澄清：Excel 报表生成脚本

## 0. 样例数据说明
老师未提供 sales_raw.xlsx，本方案自行构造一份含空值、重复行、负数量的样例数据，
放在 data/sales_raw.xlsx，用于验证脚本正确性。

## 1. 目标
读取 sales_raw.xlsx，清洗脏数据，按销售员和地区汇总销售额，输出 report.xlsx。
不得修改原始文件。

## 2. 输入
- 文件：data/sales_raw.xlsx
- 字段：日期、销售员、产品、数量、单价、地区
- 脏数据类型：空值、重复行、负数量、数量为0

## 3. 输出
- 文件：output/report.xlsx
- 四个工作表：
  1. 明细清洗后：清洗后的完整明细
  2. 按销售员：销售员、销售额
  3. 按地区：地区、销售额
  4. 总览：月度总额（一行）

## 4. 清洗规则
- 删除关键字段（日期、销售员、产品、数量、单价、地区）缺失的行
- 剔除数量 <= 0 的行
- 按全字段去重

## 5. 统计规则
- 销售额 = 数量 × 单价
- 按销售员汇总销售额
- 按地区汇总销售额
- 月度总额 = 所有有效行销售额之和

## 6. 边界与异常
- 文件不存在 → 明确中文提示，不崩溃
- 空文件 → 明确中文提示，不崩溃
- 无有效数据 → 明确中文提示，不崩溃
- 原始文件只读，禁止写回

## 7. 验收标准
- 一键运行 python src/sales_report.py 能生成 report.xlsx
- 四个工作表齐全
- 统计数值与人工核对一致
- 异常输入有可读提示，不崩溃
